# Supply-Chain-Analytics-Portfolio-Faria-Zulfiqar-IBA-Fall2026
This repository contains a supply chain and procurement analytics project built on a synthetic purchase order dataset for a fictional company, Chenab Motors Limited.

It includes work related to the product's formulation, market positioning, and/or supply chain and business analysis (e.g., sales, distribution, or production data), depending on the project's specific focus at Abbott.
